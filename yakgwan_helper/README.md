# 약관 맞춤 요약 (yakgwan_helper)

보험 약관 PDF를 올리고 내 정보(나이, 성별, 수술 이력, 지병, 가입 목적, 고지 질문 답변 등)를 입력하면,
**수백 쪽 약관에서 나에게 해당하는 내용만** 골라 요약해 주는 웹사이트입니다.
정보 입력 없이 **상품 전체 요약**만 받아 볼 수도 있습니다.

---

## 어떻게 동작하나요?

```
[브라우저]                         [내 서버 (app.py)]                     [Claude AI]
 1. 약관 PDF 업로드  ───────────▶  pdfplumber로 쪽마다 글자 추출
                                    (스캔본이면 PDF 그대로 사용)
 2. 내 정보 입력 + "요약 시작" ──▶  약관 원문(쪽 번호 표시) + 내 정보 ──▶  요약 작성
 3. 결과가 실시간으로 보임   ◀───  글자 조각을 바로바로 전달        ◀──  (근거 쪽 [p.12] 표시)
 4. 추가 질문             ──────▶  같은 약관 + 질문 ────────────────▶  답변 (캐시라 더 싸고 빠름)
```

- **긴 약관**: 지금 쓰는 AI 모델(Claude Opus 5.5)은 한 번에 약 100만 토큰을 읽을 수 있어서 보통 수백 쪽 약관도 통째로 넣습니다.
  기본 한도(`MAX_DOC_TOKENS`=50만 토큰)를 넘으면 **면책, 감액, 고지의무, 해지환급금** 같은 핵심 단어와
  **내 지병·목적 관련 단어**가 많이 나오는 페이지를 골라서 보냅니다.
- **근거 표시**: 요약의 중요한 문장마다 `[p.12]`처럼 약관 쪽 번호가 붙어서 원문을 바로 확인할 수 있습니다.
- **개인정보**: 입력한 건강 정보는 요약할 때만 AI로 보내고, 서버에는 저장하지 않습니다. 업로드한 약관은 서버 메모리에만 있다가 3시간 뒤 지워집니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `app.py` | 웹 서버. 업로드 받기, 요약 요청 받기, 비밀번호 확인 |
| `pdf_reader.py` | PDF에서 쪽마다 글자 추출, 스캔본 판별 |
| `summarizer.py` | **AI에게 보내는 지시문(프롬프트)**, 페이지 고르기, Claude 호출. 요약 항목을 바꾸고 싶으면 여기를 고치면 됩니다 |
| `static/index.html` | 화면 (입력 폼) |
| `static/app.js` | 화면 동작 (업로드, 결과 실시간 표시, 추가 질문) |
| `static/style.css` | 디자인 (다크모드, 모바일, 인쇄 지원) |
| `.env.example` | API 키 설정 예시 |
| `run.bat` | 윈도우에서 더블클릭으로 실행 |
| `Dockerfile` | 인터넷에 배포할 때 사용 |

## 내가 해야 하는 일 (처음부터 순서대로)

### 1단계. Claude API 키 만들기 (5분)

AI를 쓰려면 API 키가 필요합니다. **claude.ai 구독(Pro/Max)과는 별개**이고, 쓴 만큼 돈을 냅니다.

1. https://console.anthropic.com 에 가입/로그인
2. **Settings → Billing** 에서 카드 등록 후 크레딧 충전 (처음엔 $5~10이면 충분)
3. **Settings → Limits** 에서 월 사용 한도를 정해 두면 과금 걱정이 줄어듭니다 (예: $20)
4. **API Keys → Create Key** → `sk-ant-...` 로 시작하는 키 복사
   - 키는 한 번만 보이니 메모장에 저장해 두세요. **절대 GitHub에 올리면 안 됩니다.**

### 2단계. 내 PC에서 실행하기 (윈도우 + Anaconda 기준)

1. 이 저장소를 내려받습니다 (GitHub에서 **Code → Download ZIP** 후 압축 풀기, 또는 `git clone`).
2. **Anaconda Prompt**를 열고 `yakgwan_helper` 폴더로 이동합니다.
   ```
   cd C:\경로\insurance_project\yakgwan_helper
   ```
3. 필요한 패키지를 설치합니다 (처음 한 번만).
   ```
   pip install -r requirements.txt
   ```
4. API 키 파일을 만듭니다.
   - `.env.example` 파일을 복사해서 이름을 `.env` 로 바꿉니다.
   - 메모장으로 `.env`를 열고 `ANTHROPIC_API_KEY=` 뒤에 1단계에서 받은 키를 붙여넣고 저장합니다.
5. 서버를 켭니다. `run.bat`을 더블클릭하거나, Anaconda Prompt에서:
   ```
   python -m uvicorn app:app --port 8000
   ```
6. 브라우저에서 **http://127.0.0.1:8000** 을 엽니다.

> 맥/리눅스: 터미널에서 같은 폴더로 이동한 뒤 3~6번을 똑같이 하면 됩니다.

### 3단계. 사용해 보기

1. 보험사 홈페이지 → **상품공시실**에서 약관 PDF를 받습니다. (생명보험협회·손해보험협회 공시실에서도 받을 수 있어요)
2. PDF를 올립니다 → 쪽수와 추정 상품명이 표시됩니다.
3. **상품 전체 요약** 또는 **내 상황 맞춤 요약**을 고릅니다. 맞춤 요약은 아는 항목만 채우면 됩니다.
4. **요약 시작** → 1~3분 안에 결과가 실시간으로 나옵니다.
5. 더 궁금한 건 아래 **추가 질문**에 물어보세요. (예: "갑상선암은 일반암으로 보장되나요?")
6. **인쇄 / PDF 저장** 버튼으로 결과를 저장할 수 있습니다.

### 4단계. 결과 품질 확인하기 (중요)

AI 요약은 틀릴 수 있습니다. 처음 몇 번은 꼭 이렇게 확인하세요.

- 요약에 붙은 `[p.쪽번호]`를 열어 원문과 맞는지 확인
- 내가 잘 아는 상품의 약관으로 먼저 시험해 보기
- 결과가 부족하면 `summarizer.py`의 `GENERAL_TASK` / `PERSONAL_TASK` 문구를 고쳐서 원하는 항목을 추가
- 더 꼼꼼하게 읽게 하려면 `.env`에 `CLAUDE_EFFORT=high` (대신 느리고 비쌈)

### 5단계. 인터넷에 공개하기 (선택)

남들도 쓰게 하려면 서버를 인터넷에 올려야 합니다. 가장 쉬운 방법은 **Render.com**입니다.

1. 이 저장소를 GitHub에 올립니다 (`.env`는 `.gitignore`에 있어서 올라가지 않습니다).
2. https://render.com 가입 → **New → Web Service** → GitHub 저장소 연결
3. 설정:
   - **Root Directory**: `yakgwan_helper`
   - **Runtime**: Docker (폴더의 `Dockerfile`을 자동으로 사용)
   - **Environment Variables**:
     - `ANTHROPIC_API_KEY` = 내 키
     - `APP_PASSWORD` = 아무 비밀번호 (**꼭 설정하세요.** 안 하면 누구나 내 돈으로 AI를 쓸 수 있습니다)
4. **Deploy** → 몇 분 뒤 `https://이름.onrender.com` 주소가 생깁니다.
   - 처음 접속할 때 비밀번호를 물어보고, 그 브라우저에서는 기억합니다.
   - 무료 요금제는 한동안 안 쓰면 잠들어서 첫 접속이 30초쯤 느립니다.

> Railway, Fly.io, AWS 등 Docker를 지원하는 곳이면 어디든 같은 방법으로 올릴 수 있습니다.
> 여러 사람이 동시에 많이 쓰면, 업로드한 약관을 메모리 대신 DB나 저장소에 보관하도록 바꿔야 합니다.

## 비용은 얼마나 드나요?

AI 요금은 읽은 글자 양(토큰)에 비례합니다. Claude Opus 5.5 기준 입력 100만 토큰당 $4, 출력 100만 토큰당 $20입니다.

| 상황 | 대략적인 비용 |
|---|---|
| 300쪽 약관 첫 요약 (약관 약 30만 토큰이라고 가정) | 약 $1.5~2 |
| 5분 안에 다시 요약하거나 추가 질문 (캐시 적용) | 약 $0.1~0.3 |
| 50쪽 짧은 약관 | $0.3 안팎 |

- 한글 약관의 실제 토큰 수는 문서마다 다르므로, 업로드 후 화면에 표시되는 정보와 콘솔의 **Usage** 메뉴로 확인하세요.
- 비용을 줄이려면 `.env`에 `CLAUDE_EFFORT=low` 를 넣거나, `MAX_DOC_TOKENS`를 낮추세요 (예: 200000 → 관련 쪽만 골라서 보냄).
- 더 싼 모델을 쓰려면 `CLAUDE_MODEL=claude-sonnet-5-5` (약 절반 가격, 품질은 조금 낮을 수 있음).

## 설정값 (`.env`)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (필수) | Claude API 키 |
| `APP_PASSWORD` | 없음 | 설정하면 사이트를 쓸 때 비밀번호를 물어봄. 공개 배포 시 필수 |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 사용할 AI 모델 |
| `CLAUDE_EFFORT` | `medium` | AI가 얼마나 깊이 생각할지: `low` / `medium` / `high` |
| `MAX_DOC_TOKENS` | `500000` | 이보다 긴 약관은 관련 쪽만 골라서 보냄 |
| `MAX_OUTPUT_TOKENS` | `32000` | 요약 결과 최대 길이 |
| `MAX_UPLOAD_MB` | `50` | 업로드 최대 크기 |

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 화면 위에 "API_KEY가 설정되지 않았습니다" | `.env` 파일 이름(앞에 점), 위치(`app.py`와 같은 폴더), 키 붙여넣기 확인 후 서버 재시작 |
| "API 키가 올바르지 않습니다" | 키를 다시 복사하거나 콘솔에서 새로 만들기 |
| "PDF를 읽지 못했습니다" | 암호가 걸린 PDF일 수 있음. 보험사 공시실에서 다시 받기 |
| 스캔본이라고 나옴 | 글자가 이미지로 된 PDF. 600쪽·30MB 이하면 그대로 분석하지만 느리고 비쌈 |
| 요청이 너무 많다는 오류 | 콘솔의 사용 한도(Rate limit)에 걸린 것. 잠시 후 다시 시도 |
| `pip` 명령이 없다고 나옴 | 일반 명령 프롬프트 말고 **Anaconda Prompt**에서 실행 |

## 앞으로 붙일 수 있는 기능

- 상품 2개 약관을 나란히 비교
- 내 정보 저장(브라우저)해서 다른 약관에도 바로 적용
- 요약 결과를 Excel(통계테이블)로 내보내기 — 같은 저장소의 `benefit_extractor2.py` 와 연결
- 로그인 + 사용량 제한 (여러 사람에게 공개할 때)
