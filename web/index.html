통계테이블 작성

상품 약관에서 보험금 지급기준표를 찾아 통계테이블 초안 엑셀을 만들어 드립니다.

STEP 1

약관 내려받기

하나생명 홈페이지 → 상품공시실에서 상품 약관(PDF)을 내려받습니다. 상품별 Word 약관(.docx)도 됩니다.

STEP 2

약관 선택 후 실행

약관 파일이나 폴더를 고르고 [실행]을 누릅니다. 급부코드표가 있으면 함께 고르세요.

STEP 3

결과 확인 · 내려받기

노란색 행은 확인이 필요한 항목입니다. 엑셀로 내려받아 검토하세요.

약관 선택 · 실행

약관 파일 선택파일은 이 PC 안에서만 처리되고 밖으로 전송되지 않습니다
PDF·Word 약관을 고르거나 여기로 끌어다 놓으세요
엑셀(.xlsx) · 첫 열 급부코드, 둘째 열 급부코드명

결과 확인 예제 결과

알아두세요

  • 엑셀 시트: 초안(통계테이블 형식) · 특약별요약 · 급부원문(원문과 근거) · 처리결과(파일별 성공/실패)
  • 감액이 있으면 경과 구간을 나눕니다. 예) 0~12개월 : 50% / 13~999개월 : 100%
  • 문서보안(DRM)이 걸린 파일과 .doc 파일은 읽을 수 없습니다. PDF나 .docx로 올려 주세요.
  • 처음 열 때 준비에 1분 정도 걸립니다. 1,500쪽 PDF는 5분 안팎 걸립니다.
  • 중단하면 처리 중이던 결과는 저장되지 않습니다.

개정 전 통계테이블을 바탕으로, 상품코드만 바뀐 상품의 개정 후 통계테이블을 자동으로 채웁니다.

STEP 1

양식 엑셀 준비

시트 5개를 순서대로 둔 엑셀을 준비합니다.

  1. 통계테이블 작성 대상 (채워질 곳)
  2. 통계테이블 기존 (개정 전)
  3. 주보종-개별상품 관계 (SP_SPCD, SP_SPCD1)
  4. 변경전·후 상품코드 (변경전, 변경후)
  5. 급부코드 체계 (급부코드, 급부명)

STEP 2

양식 선택 후 실행

양식 엑셀을 고르고 [실행]을 누릅니다. 바뀐 상품코드를 따라 기존 행을 이어받아 1번 시트를 채웁니다.

STEP 3

검토 · 내려받기

검토_상품코드 시트의 색 표시된 상품은 직접 확인하거나 약관을 보고 작성합니다.

양식 선택 · 실행

양식 엑셀 선택원본 파일은 바뀌지 않고, 결과는 새 엑셀로 받습니다
시트 5개짜리 양식(.xlsx)을 고르거나 여기로 끌어다 놓으세요

결과 확인 예제 결과

알아두세요

  • 처리 방식: 변경후 코드의 변경전 코드를 찾아, 기존 테이블의 그 코드 행을 그대로 복사하고 주보종·개별상품코드만 새 코드로 바꿉니다. 급부코드·산출기준·지급율·면책·경과년은 기존 값 그대로입니다.
  • 상태: 완료 · 확인필요(변경전 코드가 여러 개 등) · 기존 행 없음 · 신규 · 관계테이블에 없음. 기존 행 없음과 신규는 약관을 보고 직접 작성하세요. [약관에서 추출] 탭을 쓰면 됩니다.
  • 시트는 이름이 아니라 순서로 찾습니다. 칼럼명(MAIN_PROD_CODE 등)은 위에서 10행 안에 있어야 합니다.
  • 결과 엑셀에서 그림·차트·매크로는 빠질 수 있습니다. 표 데이터는 그대로입니다.

약관을 올리면 급부마다 언제, 얼마를 지급하는지와 면책기간, 적립금 지급 여부를 한눈에 정리해 드립니다.

STEP 1

약관 내려받기

하나생명 홈페이지 → 상품공시실에서 상품 약관(PDF)을 내려받습니다. Word 약관(.docx)도 됩니다.

STEP 2

약관 선택 후 요약 보기

약관 파일을 고르고 [요약 보기]를 누릅니다. 여러 상품을 한 번에 올려도 됩니다.

STEP 3

급부별 정보 확인

특약별로 지급사유 · 지급금액 · 면책기간 · 적립금 지급 여부가 정리됩니다. 노란 표시는 원문을 확인하세요.

약관 선택

약관 파일 선택파일은 이 PC 안에서만 처리되고 밖으로 전송되지 않습니다
PDF·Word 약관을 고르거나 여기로 끌어다 놓으세요

급부별 요약 예제 결과

알아두세요

  • 약관의 보험금 지급기준표(급부명 · 지급사유 · 지급금액 표)를 읽어 정리합니다. [약관에서 추출] 탭과 같은 규칙이라 결과도 같습니다.
  • 지급금액은 약관 원문 그대로 보여 주고, 아래에 통계테이블에 들어가는 값(산출기준 · 지급율 · 감액)을 함께 적었습니다.
  • 면책기간은 지급사유의 'OO보장개시일'을 약관 본문에서 찾아 일수로 바꿉니다. 문구가 없으면 0일(면책 없음)입니다.
  • 적립금 지급은 사망 · 최초 1회 · 특정 시점 지급이면 '지급', 매년 · 1회당처럼 반복 지급이면 '미지급'으로 봅니다.
  • 규칙으로 판단이 애매한 항목은 노란색으로 표시됩니다. 꼭 약관 원문을 확인하세요.
